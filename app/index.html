Einstellungen

KI-Feedback (Claude)

Für das Feedback zu Schreiben und Sprechen ruft die App die Claude API direkt aus dem Browser auf. Dafür brauchen Sie einen eigenen API-Schlüssel von console.anthropic.com. Der Schlüssel wird nur in diesem Browser gespeichert und nur an api.anthropic.com gesendet. Ohne Schlüssel funktionieren alle anderen Teile normal.

Hören: Stimmen

Die Hörtexte liest die Sprachausgabe Ihres Browsers vor. Die Qualität hängt vom Gerät ab. Chrome und Edge haben meist gute deutsche Stimmen.

Daten

Antworten und Ergebnisse werden nur lokal in diesem Browser gespeichert.
